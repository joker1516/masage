# پوسته اندرویدی پیامرسان (WebView + اعلان بومی + فیلد آدرس سرور)

این پروژه تنها یک WebView است که سایت پیامرسان شما را روی هاست باز میکند. دیتابیس و پیامها روی سرور میمانند.
قبل از اولین اتصال، صفحهای میآید و آدرس هاست را میگیرد؛ آدرس ذخیره میشود و دیگر نیازی به تایپ مجدد نیست.

## قابلیتها
- فیلد آدرس سرور در اولین اجرا (مثال: `https://messenger.example.com`)
- اگر `http://` یا `https://` ننویسید، بهطور پیشفرض `https://` اضافه میشود
- ** هیچ نوار آدرسی بالای صفحه وجود ندارد**؛ تغییر آدرس از منوی همبرگری داخل وباپ است: ☰ ← **آدرس سرور**
- **اعلان بومی اندروید** حتی وقتی صفحه بسته است (سرویس `NotificationService` هر ۲٫۵ ثانیه سرور را چک میکند)
- وقتی روی اعلان میزنید، همان گفتگو در داخل برنامه باز میشود
- اعلان گفتگوهای خاموش (muted) و پیامهای خودتان نمایش داده نمیشود
- مجوز اعلان در اندروید ۱۳ به بالا هنگام اتصال درخواست میشود
- مجوزهای دوربین، میکروفون و فایلها از WebView درخواست میشود
- آپلود فایل و عکس از گالری یا دوربین کار میکند
- گواهیهای نصبشده توسط کاربر هم پذیرفته میشود (برای گواهی محلی مفید است)

## ساخت APK
1. Android Studio را باز کنید ← **Open** ← پوشه `messenger-apk-wrapper` را انتخاب کنید.
2. صبر کنید Gradle Sync تمام شود (اولین بار کمی طول میکشد).
3. برای تست: گوشی را وصل کنید ← Run ▶.
4. برای APK نهایی:
   **Build → Build Bundle(s)/APK(s) → Build APK(s)**
   فایل خروجی در:
   `app/build/outputs/apk/debug/app-debug.apk`
5. بدون اندروید استودیو: فایل `BUILD_ONLINE.md` را دنبال کنید (GitHub Actions).

## نکات مهم
- آدرس را بدون `/index.html` وارد کنید؛ برنامه خودش `index.html` را اضافه میکند.
  مثال درست: `https://example.com/messenger`
- اگر هاست داخل شبکه محلی است و HTTPS ندارید، آدرس را با `http://` وارد کنید
  (مثلاً `http://192.168.1.10:8080`). اما میکروفون/دوربین مرورگر در HTTP غیرمحلی
  کار نمیکند؛ برای تماس صوتی/تصویری حتماً HTTPS لازم است.
- اگر دامنه عوض شد: منوی همبرگری ← **آدرس سرور** ← آدرس جدید ← ذخیره و اتصال.
- اگر اعلانی نیامد: Settings ← Apps ← Messenger ← Notifications را فعال کنید و مطمئن شوید
  در تنظیمات داخل پیامرسان، «اعلانها» خاموش نشده باشد.
- یادتان نرود نسخه اصلی (`messenger-cpanel-v2.zip`) را روی هاست آپلود کنید؛
  بدون سرور، APK چیزی برای نمایش ندارد.
